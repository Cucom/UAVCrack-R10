# Release availability

The v1.0.0 weights and ONNX files are hosted as public GitHub Release assets.
Use the versioned links in README.md; no temporary file-sharing access codes
are used. The release and its assets are to be retained for at least 90 days
from the actual public publication time. For publication on 2026-10-29 this
means at least through 2027-01-27; a later publication moves that date forward.

SHA256SUMS.txt records immutable attachment hashes. Keep the repository public
and retain the release/assets for the required interval. GitHub hosting is not
a contractual 90-day availability guarantee; the repository owner maintains
the published resources. Future model versions should use a new version tag
instead of replacing the frozen v1.0.0 assets.
